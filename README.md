# 异界花坊 · 合2花店（H5 原型，竖向 9×7）

模仿《浪漫餐厅》合 2 玩法的花店经营小游戏，纯静态 H5，可直接 GitHub Pages 试玩。

线上地址：https://logo749.github.io/flower-merge/

## 玩法

- 棋盘竖向 9 行 × 7 列，开局有 26 格被蛛网封住（里面各困着一株花苗）
- 底部三块花圃：星露花（默认）、蜜穗花（Lv1）、月铃花（Lv3），点花圃扣 1 体力出花，花落在花圃旁的空格
- 同种同阶两两合并升一阶：花苗 → 花苞 → 花枝 → 花束 → 花篮 → 花艺作品
- 把同种同阶的花拖到蛛网格上即可清网并升阶
- 顶部订单卡（3 槽，不超时）凑齐即可交付换金币；交付即刷新新订单
- 升级花店解锁新花圃并提升暴击（8% 起，每级 +3%，上限 20%）

## 操作

- 点选：轻点花格选中，再点同种同阶的花合并
- 拖动：按住花格拖到目标格松手，合并 / 移动 / 清网
- 花圃拖动：同种同阶花圃可合成，产出翻倍

## 美术

30 张花材图标（5 花系 × 6 阶）+ 花房背景由图像模型生成，仿 3D 果冻黏土质感、透明底 WebP；若图片加载失败自动回退程序化 SVG。

## 部署

`.github/workflows/pages.yml` 在 push 到 main 时自动发布到 GitHub Pages。
首次使用需在仓库 **Settings → Pages** 把 Source 选为 **GitHub Actions**（一次即可）。
