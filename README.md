# 异界花坊 · Merge Flower Shop

仿《浪漫餐厅》合 2 玩法的竖屏小游戏原型：花圃产花 → 同阶两两合并 → 凑满订单交付 → 金币升级花店。

- **棋盘 9×7 = 63 格**，固定在屏幕下半部，不扩格、不做付费扩格。
- **花圃**是唯一产出源：点一下扣 1 点体力，产 1 株花苗；同系同级两个花圃可拖动合并，单次产出 1 → 2 → 3 株。
- **六阶花材**：花苗 / 花苞 / 花枝 / 花束 / 花篮 / 花艺作品，价值 1 / 2 / 4 / 8 / 16 / 32；同阶两两合并，六阶不可再合。
- **暴击**：8% 起，每级 +3 个百分点（上限 20%），暴击直接产三阶花枝。
- **蛛网**：开局 12 格封锁，每格压 1 株花苗，与相邻同阶合并后解锁该格。
- **订单 3 槽**，不超时、不作废；金币 = 需求价值 × 档位系数（6/7/8/9），向上取整到 5。
- **体力**：上限 100，正式 2 分钟回 1 点，离线照常恢复；合并、交付、升级都不耗体力。
- **花店五级**：200 / 1500 / 6000 / 16000 / 30000，每级 +3% 暴击、解锁新花系、订单换档。
- **满级拆束**：六阶花艺作品点一下拆成 4 株花苗。

## 操作

点花圃产出；点一件花材再点同系同阶另一件即合并；也可以直接拖动花材到目标格；点六阶花艺作品拆束。

「任务·设置」面板里可开体力加速（6 秒 1 点）、加满体力、+1000 金币、重置存档。
